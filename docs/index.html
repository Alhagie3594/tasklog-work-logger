📝 tasklog

Stop forgetting what you worked on. Log tasks from your terminal in 2 seconds.

🔥 The Problem

Every day you spend 5-10 minutes trying to remember what you did for standups, timesheets, or weekly reports. tasklog solves this with instant logging.

⚡ How It Works

$ tasklog add "Fixed login bug"
✓ Task saved

$ tasklog today
Today's tasks:
  • Fixed login bug
  • Reviewed pull requests

$ tasklog list
All tasks:
  [2026-05-19 14:30:15] Fixed login bug
  [2026-05-19 09:15:00] Reviewed pull requests
