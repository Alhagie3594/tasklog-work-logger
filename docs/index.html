tasklog - Work Logger for Developers

📝 tasklog

Stop forgetting what you worked on. Log tasks from your terminal in 2 seconds.

🔥 The Problem

Every day you spend 5-10 minutes trying to remember what you did. tasklog solves this with instant logging.

⚡ Commands

tasklog add "Fixed login bug"     # Log a task
tasklog today                      # Show today's tasks
tasklog list                       # Show all tasks
tasklog undo                       # Remove last task

📥 Download

To get the aarch64 binary (required for exam):

  1. Go to GitHub Actions
  2. Click the latest workflow run (green checkmark)
  3. Scroll down to "Artifacts"
  4. Download tasklog-aarch64

Or build from source:

git clone https://github.com/Alhagie3594/tasklog-work-logger.git
cd tasklog-work-logger
cargo build --release
